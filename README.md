## Screenwriting software

Full programs for writing a script. All of these have public source on GitHub.

- [Trelby](http://www.trelby.org/) - Free screenwriting program for Windows and Linux. Imports and exports many formats, including Fountain.
- [STARC](https://starc.app) - Open-source screenwriting program for writing, planning, and producing. Successor to KIT Scenarist.
- [KIT Scenarist](https://github.com/dimkanovikov/KITScenarist) - Older open-source screenwriting program. Development moved to STARC; this repo is archived.
- [Beat](https://github.com/lmparppei/Beat) - Simple screenwriting app for Mac, built around Fountain.
- [Scrite](https://www.scrite.io) - Cross-platform screenwriting program with structure tools and reports.
- [Open Draft](https://github.com/Proteus-Technologies-Private-Limited/OpenDraft) - Free screenwriting program with a beat board and live collaboration. Desktop and browser.
- [Scenarly](https://scenarly.com/) - Cross-platform screenwriting program.
- [Act One](https://actone.iyal.ink/) - Screenwriting program for Windows and Linux.
- [Scriptty](http://stultus.in/scriptty/) - Offline screenwriting app for Malayalam and English, including Indian two-column PDF.
- [Fonte](https://github.com/ricolandia/Fountain-Writer-Tool) - Free Fountain editor for the browser and the desktop. Also listed under Online Tools.

## Text Editors
*Must be libre or open source.*

- [Atom](https://atom.io/) – GUI text editor written in Node.js
- [Vim](https://www.vim.org/) – Time tested and widely adopted text editor originating from the Atari editor Vi
- [Emacs](https://www.gnu.org/software/emacs/) – Family of libre text editors that are characterized by their extensibility

## Command Line Tools
- [Wrap](https://wraparound.github.io/) - CLI-app that converts files written in Fountain to screenplay PDF
- [scripttool](https://rsdoiel.github.io/scripttool) - Convert between screenplay formats (Fountain, Final Draft, Fade In, and others)
- [pandoc-fountain](https://github.com/pandoc/pandoc-fountain) - Read Fountain files with Pandoc
- [Sed](https://www.geeksforgeeks.org/sed-command-in-linux-unix-with-examples/) – Searching, find and replace, insertion or deletion
- [Git](https://git-scm.com/) – Version-control system for tracking changes in code during development

## Visual Studio Code

- [Better Fountain](https://marketplace.visualstudio.com/items?itemName=piersdeseilligny.betterfountain) - Screenwriting inside Visual Studio Code: Fountain highlighting, live preview, PDF, stats, and a duration estimate

## Atom Packages

- [Fountain Package](https://atom.io/packages/fountain) – Atom package for syntax highlighting and utilities for Fountain

## Emacs

- [Fountain-Mode](https://github.com/rnkn/fountain-mode) – Fountain Mode for GNU Emacs

## Vim

- [vim-fountain](https://github.com/kblin/vim-fountain) - Fountain syntax highlighting for Vim
- [nvim-fountain](https://github.com/0mykull/nvim-fountain) - Fountain syntax highlighting for Neovim
- [Fountainwiki.vim](https://github.com/vim-scripts/fountainwiki.vim) - Adds some wikification to Fountain files
- [Goyo.vim](https://github.com/junegunn/goyo.vim) - Vim plugin for distraction free writing
- [OVIWrite](https://miragiancycle.github.io/OVIWrite/) - Writing environment built on Neovim
- [Vim Adventure](https://vim-adventures.com/) - Learn Vim the fun way

## Sublime Text

- [Fountainhead](https://github.com/derickc/Fountainhead) - Fountain screenwriting environment for Sublime Text

## Obsidian

- [Fountain Editor](https://github.com/chuangcaleb/obsidian-fountain-editor) - Fountain syntax in the Obsidian editor
- [Fountain](https://github.com/bgrundmann/obsidian-fountain) - Write Fountain in Obsidian, with index cards, outline, PDF export, and rehearsal mode
- [fountain-screenwriter](https://github.com/tlorien/fountain-screenwriter) - Another Obsidian Fountain plugin: highlighting, page layout, and mobile support

## Blender

- [Blender Screenwriter](https://github.com/tin2tin/Blender_Screenwriter) - Write a screenplay in Blender and turn scenes into 3D layouts or video-editor strips

## Online Tools

- [Fountain](https://fountain.io/) - Markup syntax for writing, editing and sharing screenplays in plain, human-readable, text
- [Screenplain](http://www.screenplain.com/) - Convert Final Draft FDX and Fountain files to PDF or HTML
- [Afterwriting](http://www.afterwriting.com) - Browser Fountain editor, PDF preview, and Final Draft to Fountain conversion
- [Screenwriter](http://proloser.github.io/screenwriter/) - Simple online screenwriting app
- [Text Mechanic](https://textmechanic.com/) – Don't want to use RegEx? Here is your saviour for manipulating text
- [Text Fixer](https://www.textfixer.com/) – Also a decent online text manipulator.
- [Behind The Name](http://www.behindthename.com/random/) – Advanced character name generator
- [Fonte](https://github.com/ricolandia/Fountain-Writer-Tool) - Free, offline, open-source Fountain screenplay editor (web + desktop) with a cultural-project module for grant applications
- [RelationCanvas](https://relationcanvas.com/) - Free web app for charting how the characters in a script relate, with a separate labeled arrow for each direction; exports PNG or SVG, no sign-up

## Story development

Tools for outline, characters, and long-form story — novels as well as scripts.

- [Manuskript](http://www.theologeek.ch/manuskript) - Open-source writing studio for novels and stories: outline, characters, plots, and world
- [bibisco](https://bibisco.com) - Novel writing software with character, architecture, and chapter tools
- [novelWriter](https://novelwriter.io) - Plain-text editor built for writing novels, with a project tree and notes
- [Kindling](https://kindlingwriter.com) - Fiction writing app that keeps the outline visible while you draft. Imports Scrivener, Plottr, yWriter, and Obsidian
- [Warewoolf](http://warewoolf.org/) - Minimal novel editor meant to be used without a mouse
- [ThiefMD](https://thiefmd.com/) - Markdown writing app with Fountain support
- [RelationCanvas](https://relationcanvas.com/) - Map a cast and label each direction of a relationship. Free, no account

## Storyboarding and breakdown

- [Storyboarder](https://wonderunit.com/storyboarder) - Draw a storyboard as fast as stick figures. Open source
- [Blender Screenwriter](https://github.com/tin2tin/Blender_Screenwriter) - From script pages to 3D scenes inside Blender
- [ScriptBreak](https://github.com/wassermanproductions/scriptbreak) - Break a script into scenes, elements, bibles, shot lists, and a timeline
- [SceneFlow](https://github.com/taruma/SceneFlow) - Line up a screenplay with picture, and check that the cut matches the script

## Interactive storytelling

Writer-facing tools for branching and game narrative. Not full game engines.

- [Twine](https://twinery.org) - Tool for telling interactive, nonlinear stories
- [ink](https://www.inklestudios.com/ink) - Open scripting language for interactive narrative, from inkle
- [Yarn Spinner](https://yarnspinner.dev) - Dialogue tool for games: write conversations, compile them, run them in an engine
- [Arrow](https://mhgolkar.github.io/Arrow/) - Visual tool for designing game narrative
- [Inform 7](https://github.com/ganelson/inform) - Language and system for writing interactive fiction in natural-looking prose
- [ChoiceScript](https://github.com/dfabulich/choicescript) - Language for multiple-choice stories and games
